Tigerbun Game
=============

Prerequisites
=============
Please note you will need a copy of gzDoom - https://zdoom.org/downloads and a copy of Doom 2. If you don't have a copy of Doom 2, you can try and use FreeDoom - https://freedoom.github.io/


Instructions
============
To run this game, you need to download gzDoom and a copy of Doom 2(or you can use FreeDom).

Ensure you put the Doom 2 or FeeDoom mods in a location which gzDoom can see.

Clone the repo, navigate to the source directory, then run the following:

`gzDoom -file .`

or drop the directory onto the gZDoom exectuable
